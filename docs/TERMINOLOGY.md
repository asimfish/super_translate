# 学科、领域与论文术语管理

网页右上角进入 **术语库**，阅读器也有 **术语设置**。无需修改代码即可增加化学、生物、材料、医学、经济学等学科，以及任意子领域。内置 AI / 计算机术语保留为只读库，可以搜索、导出，再导入自己的库继续扩展。

## 开始使用

1. 点击 **化学模板** 或 **生物模板**，获得学科、三个常用领域和八个基础示例词条。模板是维护起点，请继续补充你的专业词汇。再次点击不会覆盖已修改的词条。
2. 在 **管理学科 / 领域** 中新增学科；选择父分类即可新增领域，最多八层。可以改名或删除空分类。
3. 筛选目标分类，填写库名称后 **建立可复用库**。未选分类时创建通用库，通用库默认适用于所有论文。
4. 添加原词、中文译法、别名、备注、教材或论文来源。别名使用 `|` 分隔。词条可搜索、编辑、删除。
5. 上方选择 **新上传论文的默认设置** 或单篇论文，再选择学科 / 领域并保存。没有独立设置的论文和悬窗新上传的 PDF 会继承默认设置。选择学科时界面默认关闭内置 AI 术语，必要时可再勾选。
6. 单篇论文需要特别译法时，先选择那篇论文，再建立 **论文专用库**。其中的词条自动覆盖本篇的通用译法，也会更新继承的别名译法；不影响其他论文。

库设置支持改名、移动分类、补充说明和停用。停用保留数据且不参与翻译。论文专用库的论文归属保持固定；需要复用时导出后导入另一个库。

## 冲突与生效范围

覆盖顺序是：内置 AI 库（可关闭）→ 通用库 → 学科库 → 子领域库 → 额外选用的库 → 论文专用库。同级库按创建时间和 ID 确定顺序；额外选用的库按已保存顺序覆盖。页面显示最终使用的库，以及同名词的旧译法、新译法和来源。停用的库不会生效。

例如 `cell` 在生物论文中可译为“细胞”，在电化学论文中可按专业要求译为“电化学单元”。两篇论文绑定各自的领域后，译法不会跨领域混合。

术语约束适用于 DeepSeek、Kimi、OpenAI、Anthropic、智谱、Gemini、Qwen、豆包的标准 / 高质量 AI 翻译。快速 Google 翻译不支持。翻译仅向所选供应商发送当前段落命中的术语，不发送词条备注或来源。模型仍可能偏离译法，译后会给出术语一致性提示。

每次任务启动时固定术语快照，并传入隔离工作进程；正在运行的任务不会因网页编辑术语而改变。修改术语后请重新翻译；已有 PDF 保持原样，旧术语版本的译文缓存不会用于新版本。

## 批量维护与分享

CSV 使用 UTF-8，表头必须有 `source,translation`，可选 `aliases,notes,reference`。含逗号的字段请使用标准 CSV 双引号转义。

```csv
source,translation,aliases,notes,reference
gene expression,基因表达,GE,分子生物学语境,教材
activation energy,活化能,Ea,化学反应语境,教材
```

也可以导入版本化 JSON，系统导出的文件可直接导入其他库：

```json
{
  "schema_version": 1,
  "library": {"name": "分子生物学常用术语", "description": "课题组维护"},
  "entries": [
    {"source": "gene expression", "translation": "基因表达", "aliases": ["GE"], "notes": "", "reference": "教材"}
  ]
}
```

选择文件或粘贴内容，再选择 **保留已有译法** 或 **用导入内容覆盖**。每次最多 1000 词条、2 MiB。重复源词、非法字段或不完整行会拒绝整批，不会留下半次导入的数据。英文原词忽略大小写并做 Unicode 规范化。

导出超过 1000 词条或单份过大的库时，会分成多个可直接导入的 JSON 文件；浏览器可能要求允许多文件下载。导出内容不携带账号、论文 ID 或凭据，导入目标由接收者选择。系统不自动导入分类或绑定，避免覆盖接收方的使用范围。

每个工作区最多 500 分类、200 库、20000 自定义词条；每库最多 5000。现有 `corpus.json` 和 CLI 发布语料继续使用原有维护方式，网页用户库存放在 SQLite 四张新增表中，不改写发布语料。

## API

所有接口使用现有登录和账号隔离规则，前缀 `/api/terminology`：

| 路径 | 操作 |
| --- | --- |
| `/categories`、`/categories/{id}` | 列表、新增、改名、删除空分类 |
| `/libraries`、`/libraries/{id}` | 列表、新增、设置、删除库 |
| `/libraries/{id}/entries`、`/entries/{entry_id}` | 分页搜索、词条增删改 |
| `/libraries/{id}/import` | CSV / JSON 原子导入，冲突策略 keep / overwrite |
| `/libraries/{id}/export` | 带 schema_version 的 JSON，next_offset 分页 |
| `/profile` | 工作区默认设置 GET / PUT |
| `/papers/{id}/profile` | 单篇设置 GET / PUT / DELETE（恢复继承） |
| `/papers?q=...` | 当前账号的论文查询 |
| `/resolve?paper_id=...` | 已保存设置的解析结果、冲突和内容指纹 |
| `/templates/chemistry`、`/templates/biology` | 添加可编辑入门模板 |

跨账号的分类、库、词条、论文绑定、导出和解析请求均返回 404。翻译配置中的 `terminology=None` 保留旧默认行为；显式空对象关闭内置术语。实现决策见 [ADR-0005](adr/0005-scoped-terminology-libraries.md)。
