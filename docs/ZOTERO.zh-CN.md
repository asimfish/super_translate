# Zotero 安装与使用教程

SuperTranslate 可以在 Zotero 文献库、论文侧栏和 PDF 阅读器中翻译论文。完成后只新增 **中文版《论文名字》** 附件，保留原英文 PDF、笔记和批注。Web、macOS 悬窗和 Zotero 共用同一个翻译服务；相同服务和账号下的模型设置、文档记录、去重与任务状态互通。

当前插件为 **0.2.2 预览版**，安装范围为 **Zotero 10.0.x**。已实测 macOS 上的 Zotero 10.0.4 / 10.0.6；Zotero 7–9、Windows 和 Linux 尚未做原生验收。悬窗需要 macOS 13+，Zotero 插件不要求先安装悬窗。

## 先准备好三样东西

- 一个可连接的 SuperTranslate 服务地址，例如 `https://translate.example.com`，或自己电脑上的 `http://127.0.0.1:8001`。
- 该服务的用户名和密码，由部署者创建。它们不是 Zotero 账号，也不是模型厂商账号。
- 至少一家翻译供应商的可用 API Key；已有账号设置可以复用。插件本身不包含免费云服务、账号或密钥。

如果你已经在网页版或悬窗中成功翻译，直接使用同一地址和账号，跳到「安装插件」。否则先按下面步骤启动本机服务。学校或团队统一部署时，只需要部署者准备服务，其他人不用安装 Python。

## 没有服务：先在本机启动

需要 Git、[uv](https://docs.astral.sh/uv/getting-started/installation/) 和 Python 3.10+。以下命令在新克隆的目录执行，不要用模板覆盖已有 `.env`。

```sh
git clone https://github.com/asimfish/super_translate.git
cd super_translate
uv sync --frozen
cp .env.example .env
```

用下面命令生成一段本机加密密钥，将输出填入 `.env` 的 `PAPER_CHINA_CREDENTIAL_ENCRYPTION_KEY=` 后面。只生成一次并妥善保存；升级时沿用原值。它用于加密保存各账号的供应商 API Key。

```sh
uv run python -c "import base64, secrets; print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())"
```

创建第一个账号，命令会隐藏输入密码。`--scope local` 让这个账号使用本机已有文档库及服务器默认供应商配置。团队的其他账号不加该参数，各自使用独立文档库和 API Key。

```sh
uv run python scripts/manage_users.py create reader --scope local
uv run uvicorn app.main:app --host 127.0.0.1 --port 8001 --workers 1
```

保持服务终端运行。浏览器打开 <http://127.0.0.1:8001>，登录 `reader`，在 **API 设置** 中选择供应商、填写自己的 API Key、选择模型并保存。可以先上传一份 PDF，确认能完成翻译，再连接 Zotero。Linux 本机部署还需安装 CJK 字体，例如 Debian/Ubuntu 的 `fonts-noto-cjk`。Docker 和 HTTPS 部署见 [部署指南](DEPLOYMENT.md)。

服务地址只填协议、主机和端口，不要加 `/api`、`/docs` 或其他路径。上面启动的是 **8001**；插件默认的 **18001** 只适用于确实运行在该端口的服务或已有隧道，需按实际情况修改。插件不会自动启动服务器或建立 SSH 隧道。连接另一台电脑时使用部署者提供的 HTTPS 地址。

## 安装插件

1. 下载 [supertranslate-zotero-0.2.2.xpi](https://github.com/asimfish/super_translate/releases/download/zotero-v0.2.2/supertranslate-zotero-0.2.2.xpi)。[发布页](https://github.com/asimfish/super_translate/releases/tag/zotero-v0.2.2)同时提供校验清单与对应源码。
2. 在 **Zotero** 中打开 **工具 → 插件**，点击齿轮，选择 **从文件安装插件…**，打开下载的 `.xpi` 并确认安装。该文件交给 Zotero 安装，无需解压，也无需在浏览器中安装。可参考 [Zotero 官方插件安装说明](https://www.zotero.org/support/plugins)。
3. 打开 **工具 → SuperTranslate · 翻译设置与任务**，填写服务地址、用户名和密码，点击 **登录并连接**。
4. 确认设置页显示连接成功，并能读取供应商、模型目录和任务。若未出现菜单，确认插件已启用，必要时重启 Zotero。

## 翻译第一篇论文

1. 在文献库中选中带有 **已下载到本地的 PDF** 的论文条目。若附件还是云端占位文件，先下载并打开一次。
2. 右键选择 **翻译论文并保存译文…**；也可使用右侧 **论文翻译** 侧栏，或 PDF 阅读器工具栏的 **译** 按钮。
3. 选择供应商、模型和质量。首次建议使用 **均衡**；若要使用 DeepSeek Flash，选择你的账号模型目录中实际可用的 Flash 模型，点击 **应用翻译设置** 后再提交。
4. 查看侧栏的百分比、进度条和当前阶段。阅读器的「译」按钮旁也会显示进度。上传与排队可能暂时没有百分比，等待服务返回进度即可。
5. 完成后，在原论文下面找到 **中文版《论文名字》**，双击阅读，或点击 **打开译文**。Zotero 设置了外部 PDF 阅读器时会遵循该设置；英文原附件不会被替换。

同一 PDF 重复提交会复用任务或已有译文，避免重复归档；同名但内容不同的文件保留为不同内容版本。原文在任务期间被替换时会阻止错误归档并提示原因。

## 模型、批量、文档库与恢复

支持 DeepSeek、Kimi、OpenAI、Anthropic、智谱、Gemini、Qwen 和豆包。供应商接口返回的账号模型与内置参考模型分别显示；**目录列出不等于账号一定有调用权限**。可搜索模型、手动输入模型或豆包 Endpoint ID，点击 **更新模型目录** 主动刷新；连接后每五分钟同步。API Key 先在网页版设置，Zotero 无需重复填写。详细规则见 [模型目录](MODEL_CATALOG.md)。

**应用翻译设置** 会更新该服务账号的默认模型，网页版和悬窗也会使用它；质量选择中的 **快速** 档使用 Google，不使用所选的 LLM 模型。修改设置后先应用，再提交新任务。

可以一次选中最多 20 条论文；插件同时提交最多两篇、并发查询最多四个文档，实际翻译并发由服务控制。这是批量限制，不代表任意 20 篇论文均已通过版式验收。需要中止时点击 **取消翻译**，等待服务确认；重新打开 Zotero 会同步服务端任务，已归档译文不会重复添加。

在设置页可以搜索共享文档库，按导入时间或标题排列，查看导入历史和内容版本，打开中文 PDF。**整理重复与标题** 使用服务端的文档整理功能，不会改写 Zotero 原文附件标题。术语库可在网页版按学科、领域、论文维护并导入扩展，见 [术语库指南](TERMINOLOGY.md)。

## 常见问题

- **服务器未连接 / 连接被拒绝**：先用浏览器打开同一服务地址；本机确认服务终端还在运行，并核对 8001 / 18001 端口。远程地址必须使用 HTTPS。换网络或隧道后点击重新连接。
- **用户名或密码错误 / HTTP 401**：填写翻译服务账号；请部署者创建或重置账号。重置命令为 `uv run python scripts/manage_users.py reset-password reader`。若服务地址或账号已变，退出插件账号后重新连接。
- **API Key 未配置 / 模型不可用**：登录同一服务的网页版，在 API 设置中保存自己的 Key 和实际可调用的模型。不同服务、不同账号的配置独立，厂商余额与模型权限也需检查。
- **文档库 HTTP 404**：旧服务缺少新接口。更新本仓库主分支的服务；只更新 `.xpi` 无法补齐后端接口。
- **任务没有进度**：查看侧栏当前阶段和服务连接状态，点击 **刷新状态**。关闭 Zotero 不会停止服务端翻译；重新打开会续接。上传尚未得到服务确认时不会虚构百分比。
- **修复已暂停 / 已自动尝试若干次**：服务端质检仍发现问题或本轮恢复预算用尽。刷新只查询状态，不会重复扣费提交。有输出时可用 **查看待修复译文** 和 **质检详情** 查看草稿及问题页；草稿不会自动作为正式译文归档。引擎更新后由服务端恢复，不保证任意 PDF 永远一次成功。反馈问题时提供任务编号、问题页和去除密钥的错误信息。
- **没有新附件**：确认任务已完成、目标文献库有写入权限，且原 PDF 没有被替换。只读群组库无法添加译文；独立 PDF 的译文仍为独立附件。

## 升级、数据与卸载

升级前备份服务端 `data/` 和 `.env`；在干净源码目录运行 `git pull --ff-only`、`uv sync --frozen`，再重启单工作进程服务。先更新后端，再在 Zotero 中从文件安装新版 `.xpi`。当前预览版使用手动插件更新；安装包的更新目录指向主分支，尚未发布自动更新条目。已有任务记录和中文附件会保留。

仅选中的 PDF 会发送到指定服务，模型调用可能产生供应商费用。登录信息保存在 Zotero 密码管理器；本地任务记录按服务和账号隔离。不要分享密码、Key、会话文件或私人 PDF。

在 **工具 → 插件** 禁用或卸载即可移除插件入口和轮询；已保存的中文版是普通 Zotero 附件，会继续保留。需要清除登录信息时，先在插件设置中退出账号。插件构建、协议和原生测试范围见 [插件说明](../zotero/README.md) 与 [验收记录](../zotero/VERIFICATION.md)。
