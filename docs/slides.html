Problem · 痛点

读英文论文，卡在哪里？

01
精读一篇英文论文动辄半天术语查证、来回翻词典打断思路；中文母语者读中文的速度远快于读英文。
02
网页翻译丢公式、丢版式复制进翻译器就变纯文本：公式成乱码、图表全丢，只能对着两个窗口来回跳。
03
常见 PDF 翻译工具破坏排版公式错乱、图表错位、双栏变单栏、引用编号被改写——版式一坏，读起来比原文还累。
04
翻完没有质检漏翻、错改数字全靠肉眼发现；没有证据，不敢把译文当作可依赖的阅读版本。

Engine · 保版式引擎原理

逐对象分类，该动的才动

正文段落 → 翻译后原坐标回填
公式 Attention(Q,K,V) = softmax(QKᵀ/√d)V → 冻结
左栏正文 → 栏宽不变
右栏正文 → 栏宽不变
图 / 矢量图形 / 图内文字 → 冻结（图注翻译）
参考文献 [1][2][3] → 编号与格式冻结
可翻译文本 公式保护区 图形保护区 引用保护区
不是整页重排，是逐对象手术页尺寸、图片、矢量图形一个字节不动；只有确认为可翻译的文本块被替换。
公式、表格、算法伪代码零改动连实验数字被意外改写都会被 QA 查出来——保护区是审计对象，不是尽力而为。
译文回填自适应控制字符清理、图注压缩、重叠检查兜底；CJK 字体子集嵌入，产物体积可控。
模板版式可学习ACM / IEEE / Springer / ACL 等版式画像可从代表性 PDF 学习复用。

How It Works · 实现机制

一条确定性流水线，从解析到回滚

保护区不交给模型：公式、引用与 URL 先替换为可逆占位符，图形、表格、算法按规则冻结，译文只在原 bbox 内回填。
只接受严格变好：修复前快照、修复后全部检测器重跑，问题分未严格下降就原子回滚——每一轮都写入 *.qa.json。

Quick Start · 快速开始

两条路，都是几分钟的事

WEB · DOCKER COMPOSE

部署成课题组网站

git clone https://github.com/asimfish/super_translate.git
cd super_translate
cp .env.example .env   # 填 API key 与访问令牌
docker compose up -d --build

打开 https://你的域名 上传第一篇论文；VPS + HTTPS、备份与排障见 docs/DEPLOYMENT.md。

AGENT SKILL · CLAUDE CODE / CURSOR

装进你的 AI 编辑器

git clone https://github.com/asimfish/super_translate.git
mkdir -p ~/.claude/skills
ln -s "$PWD/super_translate/skills/paper-translate" \
      ~/.claude/skills/paper-translate

然后对话里说：「把 paper.pdf 翻译成中文，保留原版式」；Cursor 用户链到项目 .cursor/skills/ 即可。
