Problem · 读论文的人，谁没被翻译坑过

六个痛点，逐个改进

AI 论文里的 LLM，应该是“大语言模型”。公式、结构和专业语境，一起决定是否读得顺。

01 · 公式

乱码，变成一串源码

数学片段先保护，保留原始符号与位置。

02 · 版式

双栏变单栏，图表错位

以原页坐标回填中文，保留双栏、图片和页码关系。

03 · 结构

标题、加粗、斜体丢失

识别结构与样式，让论文层级清晰可读。

04 · 完整性

正文漏翻，图中文字乱翻

该翻的翻，该留的留；译后逐项质检，尝试有界修复。

05 · 术语

同一个词，译法总在变

专业术语随段落注入，学科、领域和论文词库可扩展。

Engine · 保版式引擎原理

逐对象分类，该动的才动

正文段落 → 翻译后原坐标回填
公式 Attention(Q,K,V) = softmax(QKᵀ/√d)V → 冻结
左栏正文 → 栏宽不变
右栏正文 → 栏宽不变
图 / 矢量图形 / 图内文字 → 冻结（图注翻译）
参考文献 [1][2][3] → 编号与格式冻结
可翻译文本 公式保护区 图形保护区 引用保护区
不是整页重排，是逐对象手术页尺寸、图片、矢量图形一个字节不动；只有确认为可翻译的文本块被替换。
公式、表格、算法伪代码零改动连实验数字被意外改写都会被 QA 查出来——保护区是审计对象，不是尽力而为。
译文回填自适应控制字符清理、图注压缩、重叠检查兜底；CJK 字体子集嵌入，产物体积可控。
模板版式可学习ACM / IEEE / Springer / ACL 等版式画像可从代表性 PDF 学习复用。

Quality · QA 体系

不只翻译，还要留下证据

DETECT 1漏翻检测正文、图注、公式说明、图框内多行说明仍是英文即标记。
DETECT 2保护区检测表格、伪代码、参考文献被意外改动——连实验数字被篡改都报错。
DETECT 3版面检测文本重叠、图片丢失、空白页、公式裁切，加视觉回归比对。
DETECT 4术语一致性1,066 条专业术语按块注入提示词，译后审计是否使用标准译法。

悬窗，随用随翻

常驻桌面一角，置顶、半透明。把 PDF 拖进去，译完用你习惯的阅读器打开。

PDF

How It Works · 实现机制

从原页，到可信译文

保护区不交给模型，术语随块注入：公式、引用与 URL 先替换为可逆占位符，图形、表格、算法按规则冻结；1,066 条学术术语按当前文本块注入提示词，可在网页按学科、领域、论文维护词库，支持化学 / 生物模板与 CSV / JSON 导入导出。
未过检就进入 Agentic 修复循环：QA 带缺陷清单打回该对象重译，全部检测器重跑；问题分未严格下降就原子回滚快照——每一轮都写入 *.qa.json。
