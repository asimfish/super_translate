# macOS 透明悬窗

悬窗支持拖入 PDF、选择供应商与模型、显示任务进度、检索文档与内容版本，并通过系统 PDF 阅读器打开译文。安装后可随用户登录启动；Web、悬窗和 Zotero 连接同一服务与账号时共享文档库及任务。

请按 [悬窗构建、安装与自启动指南](../desktop/README.md) 安装。需要 macOS 13+ 和 Swift 5.9 工具链；当前从源码构建本机签名 App，未提供经过公证的通用 App 安装包。

首次使用请先按 [服务准备与账号教程](ZOTERO.zh-CN.md#没有服务先在本机启动) 启动本机服务，或使用部署者提供的 HTTPS 服务地址。填写实际端口；悬窗默认的 18001 不是自动创建的服务。无需安装悬窗也能单独使用 Zotero 插件。

本次整合与验证范围见 [发布验收记录](CLIENTS_RELEASE_20261027.md)。
