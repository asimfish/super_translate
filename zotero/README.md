# SuperTranslate for Zotero

在文献库中翻译论文，将中文版 PDF 自动归档到原论文下，命名为 **中文版《论文名字》**。英文原文、笔记和批注保持原样。

当前版本：**0.2.1 预览版**。支持 Zotero **10.0.x**；已在 macOS、Zotero **10.0.4 / 10.0.6** 中验证原生安装及服务连接。已实测完成一篇真实 17 页 GFlowNet 论文。新版对齐当前悬窗的翻译服务协议，增加原生模型快捷切换、取消任务、共享文档检索与版本历史，并优化批量提交和状态同步。其他论文和原 20 篇验收仍有未解决问题，具体实测范围见验收记录。

## 安装与开始使用

1. 下载 `supertranslate-zotero-0.2.1.xpi`。
2. Zotero → **工具 → 插件**，点击齿轮 → **从文件安装插件**，选择这个 `.xpi`。插件可直接启用，无需手动复制文件。
3. 打开 **工具 → SuperTranslate · 翻译设置与任务**。填入与你的网页版或悬窗相同的服务地址、用户名和密码，点击 **登录并连接**。
4. 选一篇带本地 PDF 附件的论文，右键 → **翻译论文并保存译文…**。也可使用论文右侧「论文翻译」侧栏，或 PDF 阅读器工具栏的「译」按钮。
5. 翻译完成后，译文自动成为原论文的附件。点击 **打开译文** 即可在 Zotero 中阅读；Zotero 配置了外部 PDF 阅读器时，会遵循该设置。

插件需要可访问的 SuperTranslate 服务。默认地址 `http://127.0.0.1:18001` 适用于已有本机服务或本机转发；它不会自动创建 SSH 隧道。远程部署请填写自己的 HTTPS 服务地址。

## 日常使用

- **原生界面**：侧栏、右键菜单、阅读器入口和设置页，自动适应系统深色模式。
- **翻译进度**：侧栏将任务放在模型设置前，显示百分比、当前阶段和清晰的进度条；提交后自动滚动到任务。PDF 阅读器的「译」旁边也显示小进度条；暂停会明确显示「暂停」。上传尚未有服务进度时显示「上传中 / 等待进度」，模型输入保持焦点时进度仍会更新。
- **供应商和模型**：系统默认，以及 DeepSeek、Kimi、OpenAI、Anthropic、智谱、Gemini、Qwen、豆包。展开侧栏「切换供应商、模型与质量」，选择或手动输入模型 / 豆包 Endpoint ID，然后点击「应用翻译设置」。「更新模型目录」实际调用服务端刷新接口；登录后自动读取目录，每五分钟重新同步。已有 API Key 无需重复填写。
- **注意模型作用范围**：「应用翻译设置」会更新服务账号的默认模型，网页版和悬窗也会使用它。供应商与质量偏好按服务和账号单独保存；改了尚未应用时会拦住提交。快速档使用 Google，不使用所选 Flash / 其他模型。
- **输出**：新任务只保存中文版，附件标题为 `中文版《论文名字》`，文件名为 `中文版《论文名字》.pdf`。升级前选择过中英对照也会采用此规则；已有任务和附件保留。
- **批量**：最多选择 20 条文献，插件最多同时上传并提交两篇；状态查询最多四个并发，相同文档与重叠刷新会合并。实际翻译并发由服务控制。这里的数量限制不是 20 篇版式验收通过的声明。
- **取消**：任务进入翻译中后可点击「取消翻译」。先显示等待服务确认，确认停止后才显示已取消；可用「重试」重新提交。
- **共享文档库**：设置页可搜索悬窗、网页上传的文档，按最近 / 最早导入或标题排序，查看导入历史与内容版本，打开中文 PDF。「整理重复与标题」调用同一服务的整理功能；不改写 Zotero 原附件标题。Zotero 中原有分类、标签与附件管理继续可用。
- **去重**：同一账号、同一 PDF 内容、同一附件和输出类型的重复点击会复用已有任务。不同内容即使同名也会建立独立记录。
- **重启续接**：服务端任务继续执行；重新打开 Zotero 后自动同步。已保存的译文不会重复导入。
- **独立 PDF**：没有父论文的 PDF，译文也作为独立附件保存，并保留所属分类。
- **权限与来源**：只读文献库、尚未下载到本地的 PDF、原文件已被替换等情况，会显示具体原因。

## 失败或断线时

在侧栏或设置中的任务列表点击 **刷新状态**。上传中断可点击 **重试**；提交结果不明确时，先查询服务状态，插件不会在后台重复发起收费翻译。

**修复已暂停**表示自动尝试已停止，插件显示服务端阶段和尝试次数；刷新只查询状态，不会重新提交或修复译文。引擎更新并恢复任务后，插件继续同步。

有保留输出时，可点 **查看待修复译文**，通过系统默认 PDF 阅读器查看临时草稿；文件名带「待修复草稿」，不会自动加入正式译文附件。点 **质检详情**查看有问题的页码与原因。草稿仍可能有公式缺失、重叠或未翻译段落，不能视为通过验收。

## 数据与卸载

选中的 PDF 会发送至你指定的翻译服务，并由该服务使用供应商 API。插件不会把整个文献库上传，也不包含自己的云端账号或 API Key。模型调用可能产生你账号下的费用。

登录凭据存放在 Zotero 的密码管理器；密码不保存在插件设置中。任务和导入凭证保存在 Zotero 配置目录的 `supertranslate/` 下，按服务与账号隔离。账户退出后停止同步，但服务端任务与已有译文继续保留。

在 **工具 → 插件** 禁用或卸载可移除入口与后台轮询。已归档 PDF 是普通 Zotero 附件，卸载后仍可阅读。需要清除登录凭据时先在插件设置中退出；需要清除本地任务记录时，退出 Zotero 后备份并删除配置目录下的 `supertranslate/`。

## 实测速度与范围

在本机 Zotero.HTTP 和实际服务之间，对 20 个不同文档做只读状态查询，一轮预热后五次成对测量：旧版中位数 1,223 ms，新版 344 ms，约快 3.6 倍。真实网络有明显长尾（标准差分别约 522 / 601 ms），这不是翻译模型耗时或每次网络速度的保证。固定每请求 40 ms 的模拟基准，七次测量中位数从 819.1 ms 降为 207.7 ms。无变化的刷新不再重写任务文件。

0.2.0 重新验证了完整 17 页论文的原生上传、既有译文复用、中文版打开与重复归档保护；没有为此再次调用模型。原 20 篇论文版式验收的未解决问题仍保留，不将客户端测试视为引擎质量通过。

## 从源码构建

无需 npm 依赖安装。Node.js 20+ 用于测试，Python 3 用于构建：

```sh
cd zotero
npm test
npm run build
# 可选：20 个任务、固定 40 ms 模拟延迟的基准，不连接服务
node scripts/benchmark.cjs
```

产物位于 `dist/supertranslate-zotero-0.2.1.xpi`，`dist/SHA256.json` 记录安装包和每个运行时文件的校验值。构建使用固定 ZIP 时间戳，可重复生成相同字节。测试代码、测试文档、凭据和本地配置不会进入安装包。

更新目录当前为空，本预览版使用手动安装更新。项目维护者发布后续兼容版本时可更新 `updates.json`。尚未验证 Zotero 7/8/9、Windows 或 Linux，未扩大安装声明。

0.2.0 文档库需与最新版悬窗相同、提供 `/api/papers/{id}/library-history` 与 `/api/papers/organize` 的服务。旧服务缺少接口会显示 HTTP 404；需要更新服务。
