# SuperTranslate for Zotero

在文献库中翻译论文，将中文或中英对照 PDF 自动归档到原论文下。原文、笔记和批注保持原样。

当前版本：**0.1.0 预览版**。支持 Zotero **10.0.x**；已在 macOS、Zotero **10.0.4** 中完成原生安装及真实服务翻译验证。

## 安装与开始使用

1. 下载 `supertranslate-zotero-0.1.0.xpi`。
2. Zotero → **工具 → 插件**，点击齿轮 → **从文件安装插件**，选择这个 `.xpi`。插件可直接启用，无需手动复制文件。
3. 打开 **工具 → SuperTranslate · 翻译设置与任务**。填入与你的网页版或悬窗相同的服务地址、用户名和密码，点击 **登录并连接**。
4. 选一篇带本地 PDF 附件的论文，右键 → **翻译论文并保存译文…**。也可使用论文右侧「论文翻译」侧栏，或 PDF 阅读器工具栏的「译」按钮。
5. 翻译完成后，译文自动成为原论文的附件。点击 **打开译文** 即可在 Zotero 中阅读；Zotero 配置了外部 PDF 阅读器时，会遵循该设置。

插件需要可访问的 SuperTranslate 服务。默认地址 `http://127.0.0.1:18001` 适用于已有本机服务或本机转发；它不会自动创建 SSH 隧道。远程部署请填写自己的 HTTPS 服务地址。

## 日常使用

- **原生界面**：侧栏、右键菜单、阅读器入口和设置页，自动适应系统深色模式。
- **供应商和模型**：DeepSeek、Kimi、OpenAI、Anthropic、智谱、Gemini、Qwen、豆包；目录取自服务。可选择或手动输入模型，已有 API Key 无需重复填写。
- **注意模型作用范围**：「保存账号模型」更新服务账号的默认模型，网页版和悬窗也会使用它。插件会在按钮附近说明。
- **输出**：默认保存中英对照 PDF；可改成中文 PDF。修改后对新任务生效。
- **批量**：最多选择 20 条文献，插件依次上传并提交，实际翻译并发由服务控制。这里的数量限制不是 20 篇版式验收通过的声明。
- **去重**：同一账号、同一 PDF 内容、同一附件和输出类型的重复点击会复用已有任务。不同内容即使同名也会建立独立记录。
- **重启续接**：服务端任务继续执行；重新打开 Zotero 后自动同步。已保存的译文不会重复导入。
- **独立 PDF**：没有父论文的 PDF，译文也作为独立附件保存，并保留所属分类。
- **权限与来源**：只读文献库、尚未下载到本地的 PDF、原文件已被替换等情况，会显示具体原因。

## 失败或断线时

在侧栏或设置中的任务列表点击 **刷新状态**。上传中断可点击 **重试**；提交结果不明确时，先查询服务状态，插件不会在后台重复发起收费翻译。

「等待系统修复」和质检失败来自翻译服务，插件会如实显示。它不会把草稿标成成功，也不会在本地绕过服务的质检。此时可在网页版检查任务，等待服务修复后刷新。

## 数据与卸载

选中的 PDF 会发送至你指定的翻译服务，并由该服务使用供应商 API。插件不会把整个文献库上传，也不包含自己的云端账号或 API Key。模型调用可能产生你账号下的费用。

登录凭据存放在 Zotero 的密码管理器；密码不保存在插件设置中。任务和导入凭证保存在 Zotero 配置目录的 `supertranslate/` 下，按服务与账号隔离。账户退出后停止同步，但服务端任务与已有译文继续保留。

在 **工具 → 插件** 禁用或卸载可移除入口与后台轮询。已归档 PDF 是普通 Zotero 附件，卸载后仍可阅读。需要清除登录凭据时先在插件设置中退出；需要清除本地任务记录时，退出 Zotero 后备份并删除配置目录下的 `supertranslate/`。

## 从源码构建

无需 npm 依赖安装。Node.js 20+ 用于测试，Python 3 用于构建：

```sh
cd zotero
npm test
npm run build
```

产物位于 `dist/supertranslate-zotero-0.1.0.xpi`，`dist/SHA256.json` 记录安装包和每个运行时文件的校验值。构建使用固定 ZIP 时间戳，可重复生成相同字节。测试代码、测试文档、凭据和本地配置不会进入安装包。

更新目录当前为空，本预览版使用手动安装更新。项目维护者发布后续兼容版本时可更新 `updates.json`。尚未验证 Zotero 7/8/9、Windows 或 Linux，未扩大安装声明。
