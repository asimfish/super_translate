## 复核方法

1. 以全新、独立的 profile 和 data directory 启动实际 Zotero。不要用日常资料库测试故障注入。
2. 通过工具 → 插件安装构建出的 XPI，检查原生侧栏、右键入口、阅读器「译」按钮及设置页。
3. 连接自己的测试账号。给一条测试论文添加本地英文 PDF，提交翻译并等到服务质检完成。
4. 确认译文自动成为子附件，能在阅读器中打开，原文件字节不变。
5. 再次提交同一附件并重新启用插件，确认没有重复任务或附件。
6. 在开发专用资料库中验证断线、只读库、原文件被替换、导入后丢失任务标记等情形。恢复标记须同时匹配原父条目、标题和实际 PDF 摘要。

`npm test` 为可重复执行的协议与控制器测试；原生步骤需要实际 Zotero 和可访问的服务，不等同于 Node 模拟测试。其余操作系统、Zotero 大版本、真实网络中断时机、复杂期刊整篇版式均未据此宣称全部通过。
